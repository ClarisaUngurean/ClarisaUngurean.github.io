Waste Disposal Classifier

An image classification project developed during the AI CREATE summer program at the University of Toronto. The project explored how machine learning could be used to classify waste items and support more accurate disposal decisions.

Project Overview

The goal of this project was to create a system capable of identifying different categories of waste from images. I worked on developing and testing a classifier that could distinguish between disposal categories and explored how image classification could be applied to an environmental problem.
