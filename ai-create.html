AI Waste Disposal Classifier

A computer vision system that identifies common waste items through a live camera feed and recommends the appropriate disposal method. Developed during the University of Toronto Engineering CREATE Artificial Intelligence program.

Python · TensorFlow/Keras · OpenCV · NumPy · Pandas · Teachable Machine

The Problem

Waste sorting can become confusing when different materials require different disposal methods. This project explored how computer vision could help automate that decision by recognizing an object and recommending where it should be disposed.

What I Built

I worked on a computer vision prototype that processes a live webcam feed, identifies a waste item using an image classification model, and maps the prediction to an appropriate disposal category.

The system processes each camera frame with OpenCV, passes the image to a TensorFlow/Keras classification model, evaluates the model's confidence, and displays both the detected object and its recommended disposal method directly on the video feed.

How It Works

1. Capture

OpenCV captures images continuously from a live webcam feed.

2. Classify

Each frame is resized and normalized before being passed to the trained image classification model.

3. Recommend

Predictions with more than 65% confidence are mapped to the corresponding disposal category and displayed to the user. Lower-confidence predictions are handled separately to avoid presenting uncertain classifications as reliable results.

Live Demo

The classifier processes a live camera feed and displays its predicted waste category and disposal recommendation.

Code & Implementation

The project was developed in a Jupyter Notebook using Python, OpenCV, TensorFlow/Keras, NumPy, and Pandas.
